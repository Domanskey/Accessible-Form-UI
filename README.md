# Accessible-Form-UI
6th [project](https://roadmap.sh/projects/accessible-form-ui) of the Frontend Developer roadmap

## Requirements
- [x] Create an accessible form that is easy to use for all users.

## Goals of this project are:
+ Using ARIA attributes.
+ Using Focus state.
+ Validating inputs via JS.
+ Meeting WCAG color contrast standards.
+ Testing website for accessibility.

## How to run?
+ npm install
+ npm run dev
